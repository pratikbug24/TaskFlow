# TaskFlow - Smart Todo List

A beautiful, feature-rich todo application built with vanilla HTML, CSS, and JavaScript.

## ✨ Features

### Core Functionality
- ✅ **Add Tasks** - Create new todos with ease
- ✅ **Complete Tasks** - Mark tasks as done with a click
- ✅ **Edit Tasks** - Modify existing tasks via modal
- ✅ **Delete Tasks** - Remove tasks you no longer need
- ✅ **Persistent Storage** - All tasks saved to localStorage

### Enhanced Features
- 🎨 **Priority Levels** - High, Medium, and Low priority with color coding
- 📅 **Due Dates** - Set deadlines for your tasks
- 📁 **Categories** - Organize tasks with custom tags (Work, Personal, etc.)
- 🔍 **Search** - Quickly find tasks by text or category
- 🔄 **Filters** - View All, Pending, or Completed tasks
- 📊 **Statistics** - Track your total, completed, and pending tasks
- 🗑️ **Clear Completed** - Bulk delete finished tasks

### User Experience
- 📱 **Responsive Design** - Works great on mobile and desktop
- ⌨️ **Keyboard Shortcuts** - Press Enter to add, Ctrl+F to search
- 🎬 **Smooth Animations** - Slide-in effects and hover transitions
- 🎯 **Modern UI** - Clean, professional design with gradient background

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No server or dependencies required.

## 🎯 Usage Tips

1. **Add a task**: Type your task description and click "Add Task" or press Enter
2. **Set priority**: Choose High (🔴), Medium (🟡), or Low (🟢) priority
3. **Set due date**: Pick a deadline from the date picker
4. **Add category**: Label tasks (e.g., "Work", "Personal", "Shopping")
5. **Complete a task**: Click the checkbox on the left
6. **Edit a task**: Hover over a task and click the pencil icon
7. **Delete a task**: Hover over a task and click the trash icon
8. **Search**: Use the search bar to filter tasks
9. **Filter**: Click All/Pending/Completed to view specific task types
